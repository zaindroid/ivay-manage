# Ivay launch board

Shared kanban board for Ivay's first market release (Sat 24 Oct 2026). Every card has a priority (Blocker, High, Low) and starts unclaimed. Each developer signs in, takes the cards they want, and moves them to done. Blockers are listed first.

## Run locally

```
SESSION_SECRET=dev BOARD_PASSCODE=launch24 DATA_DIR=./data node server.js
```

Then open http://localhost:8080. There are no dependencies to install. Node 20+ is required.

`npm test` boots the server against a temp folder and checks login, claiming, priorities and persistence.

## Deploy with Zorc

`app.yaml` follows Zorc's contract:

- port 8080, with `GET /health`, `/ready`, `/version` and `/openapi.json`
- `persistent_storage` at `/data`, where `board.json` lives. On first boot the board is created from `seed-cards.json`.
- `SESSION_SECRET` is generated by Zorc
- `BOARD_PASSCODE` is required, and you supply it at deploy time through `env_overrides`. Share it with the team privately.

The server refuses to start if either variable is missing.

## How it works

- `server.js` is a plain Node HTTP server. It handles the team login (a signed cookie that lasts 30 days), a JSON store written atomically to `/data/board.json`, and live updates to every open browser over server-sent events.
- `public/index.html` is the whole front end in one file, with no build step.
- Team members are fixed in `server.js` (`PEOPLE`): Saleeta, Zain and Musharaf.
